## Overview

Magic Storage is a Terraria mod that replaces chest-hunting with a networked storage network centered on a Storage Heart block. Connect unlimited Storage Units to one Heart and access, search, and deposit all your items from a single interface anywhere in the network, with automatic crafting from stored materials directly through the interface.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Magic Storage** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Storage Network** | Connect unlimited storage units to one heart block for unified access |
| **Unified Search** | Search your entire item collection from one interface in seconds |
| **Network Crafting** | Craft items directly using materials stored anywhere in the network |
| **Compact Storage** | Storage units hold thousands of items in a compact block footprint |
